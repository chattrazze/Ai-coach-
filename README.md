# AI Coach — Garmin Dashboard

A responsive personal coaching dashboard for Garmin-powered recovery, training, nutrition and body-progress tracking.

## Modules
- Garmin readiness, sleep, HRV, Body Battery and activity overview
- Training plan and workout guidance
- Nutrition calories and macro targets
- Body progress and photo tracking UI

## Run
```bash
npm install
npm run dev
```

## Garmin integration
Keep Garmin OAuth/access tokens on the server side or in deployment secrets. Do not commit tokens to GitHub. The UI is prepared to consume a secure backend API/MCP integration.
